Methodology & sources

Y: West Texas Intermediate (WTI), Cushing, Oklahoma spot price, USD per barrel, published by the U.S. EIA and distributed via FRED series DCOILWTICO.

X: 10-year Daily Treasury Par Yield Curve Rate, quoted in percentage points, directly from the U.S. Treasury XML data feed.

Observations are inner-joined on exact YYYY-MM-DD dates. Missing and nonnumeric records are discarded. The rolling interval runs from today minus 36 calendar months through today. Daily data may be delayed or revised.

OLS fits oil = α + β × yield with an intercept. R² is computed from residual and total sums of squares. Correlation does not establish causation; this is a descriptive regression of levels, not an investment signal.

Data access & offline alternative

On opening, this single HTML file requests the official Treasury feed and the FRED CSV. Because browser CORS policies vary, it can optionally retry through public CORS relays. These relays are independent third parties and are not guaranteed to work. No API key or external JavaScript library is required.

For a fully offline analysis, import two downloaded files below. Treasury: XML from the Treasury feed (one or more files, by year); Oil: a CSV with DATE,DCOILWTICO or observation_date,DCOILWTICO columns.

No example or fabricated financial data are displayed. Results appear only after authentic data are loaded.
